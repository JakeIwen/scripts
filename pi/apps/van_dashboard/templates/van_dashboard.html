Checking attached disks…

Only current faults change a disk health badge; hover that badge for details or tap it on mobile. Unmount stops active users safely. For device-offline or USB transport faults: unmount, Reset USB, then Repair; Reset USB is blocked while storage on that port is mounted. Repair preserves the current mounted/unmounted state, runs offline filesystem repair plus read-only verification, and remounts only after success; failure quarantines the filesystem. Filesystem repair cannot heal faulty hardware, cabling, or power.
